# Mouse and keyboard reference

## Knobs

- Drag up/down (or right/left) to change the value; hold **Shift** for fine control.
- **Double-click** resets to the default value.
- **Mouse wheel** changes the value in small steps (integers and menus step by one).
- **Right-click** for: reset, type a value, modulation options and help.
- **Alt-drag**, or drag the coloured outer ring, to change the depth of a modulation.

## Displays

- Wavetable display: drag up/down to scan WT POS; double-click to open the editor.
- Filter display: drag horizontally for cutoff, vertically for resonance.
- Envelope display: drag handles for times and levels, segment handles for curves.
- LFO editor: drag points; double-click to add/remove; Shift disables snapping; right-click for shapes and grid.

## Keyboard

- **F1**: open or close help.
- **Ctrl/Cmd + S**: save preset.
- **Left / Right arrows** (when the browser is open): previous / next preset; **Enter** loads.
- **Esc**: close the browser, help or editor overlay.
