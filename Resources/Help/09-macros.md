# Macros

Eight macro knobs act as performance controls. A macro does nothing on its own: drag its handle (the small chip in the corner of each macro cell) onto the controls it should move, then set each depth with the knob rings. Turning one macro can then open a filter, add distortion and widen the unison at the same time.

- Double-click the name under a macro to rename it.
- Macros are host parameters: map them to hardware controllers or automate them in your DAW.
- When a Serum preset is imported its macro names and values are kept.
