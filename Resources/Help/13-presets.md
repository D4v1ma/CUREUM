# Presets

Click the preset name in the header to open the browser.

- The left column lists folders: **Factory**, **User** (your preset folder and its sub-folders, including **Imported**) and your **Serum** folders.
- Type in the search box to filter by name or folder. **Favourites** shows only presets you starred.
- Double-click a preset (or select it and press **Load**) to load it. The arrows in the header step through the current list.
- **Save** (disk icon) stores the current sound as a `.cureum` file in your user folder. You can type a sub-folder to organise presets.
- **Init** (menu) resets everything to a basic saw patch.

Preset files are compressed XML and include custom wavetables, LFO shapes, the matrix, effect order, macro names and hosted plugin settings, so they are self-contained.

The user preset folder defaults to `Documents/CUREUM/Presets`; change it on the GLOBAL page.
