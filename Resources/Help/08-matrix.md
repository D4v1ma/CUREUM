# Modulation matrix

The MATRIX page lists all 64 modulation slots.

- **SOURCE**: what modulates.
- **AMOUNT**: depth from -100% to +100% of the destination's full range. Drag horizontally (Shift for fine); double-click to reset. Amounts are automatable host parameters ("Mod N Amount").
- **DESTINATION**: the modulated control, grouped by module.
- **TYPE**: Unipolar (the source adds 0..amount) or Bipolar (the source swings -amount..+amount).
- **AUX (MULTIPLY)**: a second source that scales the routing. Example: LFO 1 to pitch with the Mod Wheel as aux gives classic mod-wheel vibrato.
- **CURVE / OUTPUT**: drag vertically on the text to bend the response (left half: curve) or scale the output (right half); double-click to reset.
- **ON/OFF** mutes a routing, **x** removes it.

Tick **Show used slots only** to hide empty rows. **Clear all** removes every routing.
